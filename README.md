# AI Image Generator using Stable Diffusion XL

This project is a simple AI-powered image generator built with Streamlit and Stable Diffusion XL Turbo. Users can enter a text prompt and generate unique AI-created images directly from the web interface.

The project was created to explore Generative AI, Hugging Face Diffusers, and deployment of AI applications on Hugging Face Spaces.

git clone https://huggingface.co/spaces/naveen81151325/AI-Image-Generator-SDXL

## Features

* Generate images from text prompts
* Simple and user-friendly Streamlit interface
* Powered by Stable Diffusion XL Turbo
* Fast image generation
* Deployable on Hugging Face Spaces
* Beginner-friendly project structure

## Demo

Enter a prompt such as:

"A dog wearing black sunglasses sitting on a beach during sunset"

and the application will generate an AI-created image based on the description.

## Installation

Clone the repository:

```bash
git clone https://github.com/your-username/AI-Image-Generator-SDXL.git
```

Move into the project directory:

```bash
cd AI-Image-Generator-SDXL
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
streamlit run src/streamlit_app.py
```
